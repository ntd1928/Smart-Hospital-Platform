# Bàn giao giữa thành viên và AI coding agent

Đọc AGENTS.md → CONTEXT.md → PLAN.md → TRACKING.md trước khi bắt đầu. Kiểm tra git status để bảo toàn thay đổi của người khác. Dùng branch feat/<task-id>-<ten-ngan>, không force-push main.

## Mẫu cập nhật

Đợt bàn giao hiện tại: tuần 5–6 đã được kiểm chứng local; xem docs/reports/WEEK56.md và QA-REVIEW.md. Không có blocker chức năng trong phạm vi đã chốt. Chưa commit/push; branch main vẫn ở commit khởi tạo, toàn bộ phần tích hợp nằm trong working tree để người dùng review. Việc tiếp theo của nhóm là phân công task tuần 7 từ PLAN, không cần nhập lại toàn bộ Medplum.

Để tiếp tục chạy: dùng Node/npm trong README, npm run services:up, npm run seed, rồi dev:server và dev:app. Nếu tiến trình từ phiên làm việc trước đã dừng, kiểm tra healthcheck/cổng trước khi chạy lại. Không suy ra tiến trình còn sống chỉ từ file log hoặc ghi chú context.
